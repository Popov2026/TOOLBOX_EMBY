Stunt Car Racer - jouer à deux en réseau (mode « Computer Link »)
=================================================================

Le jeu d'origine permettait de relier deux Atari ST par un câble série pour faire la course l'un
contre l'autre. Ici, ce câble passe par le réseau : chaque joueur lance scr.exe sur son PC et
retrouve l'autre joueur comme adversaire sur la piste.

Il faut que les deux joueurs aient la même version de scr.exe, la même image disque et les mêmes
réglages de physique dans scr.ini (c'est vérifié à la connexion).


1. Se relier
------------

  Sur le même réseau (maison, même box) :
    - le premier joueur appuie sur F7 (héberger une partie) ;
    - le second appuie sur F8 : la partie est trouvée automatiquement, rien à taper.
    Au premier lancement, Windows demande d'autoriser scr.exe sur les réseaux privés : acceptez.

  Par Internet (avec un serveur relais) :
    - les deux joueurs appuient sur F9 et tapent le même code de salle (lettres ou chiffres),
      puis Entrée. Avec un code vide, le jeu en invente un : donnez-le à l'autre joueur ;
    - aucun port à ouvrir sur les box : les deux PC appellent le serveur relais, qui les met en
      relation. L'adresse du serveur se règle dans scr.ini : relais = adresse:port

  À la main (adresse IP) :
    - le premier joueur appuie sur F7 ; le second lance : scr.exe --join 192.168.1.20

  F10 coupe la connexion. Un bandeau en haut de l'image indique l'état : en attente, relié (avec
  le nom de l'autre joueur et le ping), ou la raison d'un échec.

  On peut aussi lancer directement en ligne de commande :
    scr.exe --host                        héberger en réseau local
    scr.exe --joinlan                     rejoindre en réseau local (détection automatique)
    scr.exe --join ADRESSE[:PORT]         rejoindre une adresse
    scr.exe --online CODE                 rejoindre une salle du serveur relais (relais = dans scr.ini)


2. Lancer la course
-------------------

  Une fois relié :
    - les deux joueurs choisissent « 3. Computer Link » dans le premier menu du jeu ;
    - le premier à le faire devient le « maître » : il saisit les pilotes (au moins deux : les deux
      joueurs) avec « 1. Enter another driver », puis « 2. Continue », et c'est lui qui mène les
      menus (championnat, entraînement, choix du circuit) ;
    - l'autre affiche « Please wait » puis suit les mêmes écrans ;
    - en course, chacun pilote sa voiture et voit l'autre comme adversaire.

  Échap pendant la mise en relation abandonne (« Link abandoned »).


3. Ping et vitesse du jeu
-------------------------

  Le jeu d'origine attend l'autre machine à chaque étape de la course. Avec un ping (aller-retour)
  jusqu'à environ 50 ms - le cas normal entre joueurs en France - la vitesse est normale. Au-delà,
  le jeu ralentit un peu (environ 87 % à 80 ms, 76 % à 120 ms) mais ne se désynchronise pas.

  Le mode HD (F1) et les détails élevés (F5) fonctionnent aussi en multijoueur.


4. Le serveur relais
--------------------

  Il n'est utile que pour jouer par Internet. C'est un petit programme pour un serveur Linux
  (voir le dossier serveur et serveur/LISEZMOI_SERVEUR.txt). Un petit serveur virtuel à quelques
  euros par mois suffit très largement : le trafic est d'environ 300 octets par seconde par joueur.
