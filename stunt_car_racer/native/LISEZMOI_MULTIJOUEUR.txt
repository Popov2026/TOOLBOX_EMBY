Stunt Car Racer - jouer à deux en réseau (mode « Computer Link »)
=================================================================

Le jeu d'origine permettait de relier deux Atari ST par un câble série pour faire la course l'un
contre l'autre. Ici, ce câble passe par le réseau : chaque joueur lance scr.exe sur son PC et
retrouve l'autre joueur comme adversaire sur la piste.

Il faut que les deux joueurs aient la même version de scr.exe, la même image disque et les mêmes
réglages de physique dans scr.ini (c'est vérifié à la connexion).


1. Se relier et lancer la course
--------------------------------

  Les deux joueurs lancent scr.exe et choisissent « 3. Computer Link » dans le premier menu du
  jeu. Un menu s'ouvre alors par-dessus le jeu :

    COMPUTER LINK - CHOISISSEZ L'ADVERSAIRE
      Affronter Pierre                 <- joueurs trouvés sur le réseau local (automatique)
      Par Internet : code de salle     <- serveur relais (relais = ... dans scr.ini)
      Par adresse IP
      Annuler

  Flèches + Entrée pour choisir (ou la manette), Échap pour annuler.

  - Même réseau (maison) : chaque jeu qui attend dans ce menu apparaît chez l'autre. L'un des deux
    joueurs choisit « Affronter ... » : les deux jeux se relient et la mise en relation du jeu
    d'origine démarre toute seule (« Link complete »). Au premier lancement, Windows demande
    d'autoriser scr.exe sur les réseaux privés : acceptez.
  - Par Internet : les deux joueurs choisissent « Par Internet » et tapent le même code de salle
    (lettres ou chiffres). Code vide : le jeu en invente un, à donner à l'autre joueur. Aucun port
    à ouvrir sur les box : les deux PC appellent le serveur relais, qui les met en relation.
  - Par adresse IP : pour un réseau qui bloque la détection automatique.

  Celui qui a choisi l'adversaire (ou le premier arrivé dans la salle) est le « maître » : il saisit
  les pilotes (au moins deux : les deux joueurs) avec « 1. Enter another driver », puis
  « 2. Continue », et mène les menus (championnat, entraînement, circuit). L'autre affiche
  « Please wait » puis suit les mêmes écrans. En course, chacun pilote sa voiture et voit l'autre
  comme adversaire.

  F10 coupe la connexion. Un bandeau en haut de l'image indique l'état (relié, ping, ou la raison
  d'un échec).

  En ligne de commande (sans passer par le menu) :
    scr.exe --online CODE                 salle du serveur relais (relais = dans scr.ini)
    scr.exe --join ADRESSE[:PORT]         adresse d'un autre joueur qui attend (--host)
    scr.exe --host / --joinlan            héberger / rejoindre en réseau local


2. Ping et vitesse du jeu
-------------------------

  Le jeu d'origine attend l'autre machine à chaque étape de la course. Avec un ping (aller-retour)
  jusqu'à environ 50 ms - le cas normal entre joueurs en France - la vitesse est normale. Au-delà,
  le jeu ralentit un peu (environ 87 % à 80 ms, 76 % à 120 ms) mais ne se désynchronise pas.

  Le mode HD (F1) et les détails élevés (F5) fonctionnent aussi en multijoueur.


3. Le serveur relais
--------------------

  Il n'est utile que pour jouer par Internet. C'est un petit programme pour un serveur Linux
  (voir le dossier serveur et serveur/LISEZMOI_SERVEUR.txt). Un petit serveur virtuel à quelques
  euros par mois suffit très largement : le trafic est d'environ 300 octets par seconde par joueur.
